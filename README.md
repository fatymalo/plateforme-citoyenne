# CitizenConnect

Plateforme mobile intelligente de participation citoyenne développée avec **Kotlin (Jetpack Compose)** et **Spring Boot**.

## Fonctionnalités

- Signalement d’incidents
- Consultation des incidents
- Carte des incidents
- Profil utilisateur
- Vote citoyen 👍
- Notifications 🔔
- Espace administrateur 🛠️

## Technologies

- Kotlin + Jetpack Compose
- Retrofit
- Spring Boot
- MySQL

## Lancement

### Backend

```bash
cd plateforme-citoyenne-api
./mvnw spring-boot:run
```

### Android

Ouvrir le projet dans **Android Studio** puis exécuter l’application.
